# puma_2024_transplant

All R script files begin with a number indicating the order in which they were written. 
All R scripts should be run in numeric order. 

R scripts 1-4 download and filter Motus data. 

Some Motus filtering was performed manually and therefore is not present in the code. 
Motus detections filtered both via the code present here as well as via manual validation can be found in "motus_summary_21jan2026.csv" (containing summary information for each individual), and "csv4.csv" (containing all retained filtered detections). 

R scripts 5-10 contain code for running analyses present within the manuscript. 

"PUMA_Nestling_Tag_Summary_All_2024.csv" contains metadata for all individuals. 

"nest_success.csv" contains hatch rate data for all nests, experimental and non-experimental. 

"growth_with_rates.csv" contains growth rate data for all individuals.
